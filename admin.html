Connect with a GitHub token. Every change is saved to your repository as JSON, and the store reads it from there. No server needed.

Create the token in GitHub: Settings, Developer settings, Fine-grained tokens. Select only this repository and set Contents to Read and write. Without the token this page can change nothing.
